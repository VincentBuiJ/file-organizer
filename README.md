# File Organizer
- It automatically organizes folders by the file type.

## What It Does:
- Scans a directory for files
- Group files by their extension (.txt, .pdf, .py)
- Show preview of changes
- Creates organized folders by type
- Moves files into appropriate folders with user confirmation

## How to Use
- python file_organizer.py

## What I Learned
- File system operations with `os` module
- Working with dictionaries to group data
- Moving files with `shutil`
- Using `exist_ok=True` to prevent errors
